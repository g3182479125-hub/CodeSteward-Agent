# 训练项目故障基线还原设计

## 目标

将 `training-projects/python-project-template-bugfix/main.py` 恢复为录制 Bug-fix 流程所需的三处故障基线。

## 范围

- 仅修改 `add_task`、`complete_task` 和 `remove_task`。
- 不修改测试、Skill、配置、依赖或项目外的任何文件。

## 故障基线

1. 新任务 ID 使用当前任务数量加一，因此删除中间任务后可能复用 ID。
2. 完成未知 ID 时直接访问空查找结果，产生原始属性错误。
3. 删除任务时将稳定 ID 当作列表索引，可能删除错误任务或越界。

## 验证

确认文件能编译，并使用临时任务文件验证上述三种可复现行为。测试套件预期恢复为 3 个失败、2 个通过的录制基线。
