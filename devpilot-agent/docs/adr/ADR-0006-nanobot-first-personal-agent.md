# ADR-0006：后续工作回到 nanobot 个人 Agent 主线

状态：依据用户最新明确纠偏采纳。CURRENT_PLAN 3.1 接管尚未完成工作；其内容
优先于 ADR-0005 的 3.0 路线。ADR-0004 的开发审查规则及未修改的安全契约继续有效。

原因：3.0 的后续工作偏重代码交付与沙箱，只将两个 Harness 列为参考，没有定义
如何帮助用户定制自己的 Agent。用户要求以 nanobot 为基础、有选择借鉴、容易
理解维护，并明确不再处理已完成部分。

决策：P0–P5 的代码、验收及历史记录保持原样；P6 仅补未完成的执行接入，P7-01/02
明确任务组合、上下文复用和效果评测，P7-03 保留换机、恢复、回归及作品集交付。
借鉴落点见 HARNESS_ADOPTION；已有能力验证通过即复用，不以借鉴名义重构上游。
这不是新增通用插件平台、第二 Runtime 或无限 Agent 群，也不增加新产品线。

本次只修订后续计划和入口，不运行云端、不实施新增功能、不重新认证历史阶段。
