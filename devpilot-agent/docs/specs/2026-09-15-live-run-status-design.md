# 运行状态行优化

## 目标

让正在执行的聊天请求在没有新流式文本时仍说明其最后一个真实步骤，同时移除容易被误解为独立卡片的运行状态外框。

## 设计

- 状态行固定在活动消息流末尾，外观为无边框的转圈图标和一行文字。
- 文案为“运行中 · 用时 · 当前：摘要”。摘要仅来自后端最新 `goal_state.ui_summary`（没有摘要时说明正在等待模型开始处理）。
- 每次摘要变化记录本地更新时间。超过 10 秒未变化时追加“仍在等待下一步结果”，不声明不存在的扫描进度或完成百分比。
- 整个状态行只在活动 turn 存在时显示；结束后立即移除，沿用 nanobot 原生消息完成操作。
- 本次不改变后端事件、Agent 执行、确认、沙箱或超时策略。

## 验收

1. 活动请求立即显示旋转图标和无边框状态行。
2. 有 `ui_summary` 时显示为当前步骤；10 秒无更新时显示等待提示。
3. 请求结束后状态行消失。
4. 对应前端测试、lint 和构建通过。
