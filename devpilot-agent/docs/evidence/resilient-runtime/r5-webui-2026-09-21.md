### 2.1 关于旧的重放保护

对历史上被标记为“结果不明”的同参数读取，系统没有再次读取文件，而是返回“这个确切工具调用属于结果未知的旧操作，未重放；请查询或恢复”。
这不是会话锁死：同一会话随后仍能正常聊天。它只保护对应旧 operation，符合计划中“普通对话可继续、未知副作用不得重放”的边界。

## 3. 代码修复与对应证据

### `ad14ae9`：结构化临时工具结果规范化

`ContextGovernor.normalize_tool_result` 现在会把非字符串、非 content-block 列表的结构化结果序列化为稳定 JSON，再交给模型上下文；保留已有 `ToolResult`、列表内容块和超大结果持久化逻辑。
这修复了临时工具实际返回 `{"length": 4}` 后 provider message 缺少 `type` 的失败。

### `7da024a`：保留中文重复失败保护结果

`turn_outcomes.py` 的 guard 分类同时识别实际用户提示中的中文保护语句，避免 `stop_reason=tool_error` 把“重复失败保护已停止”降级成普通英文/通用工具错误。
因此 WebUI 现在显示当前尝试停止提示，并允许下一条自然语言消息继续。
