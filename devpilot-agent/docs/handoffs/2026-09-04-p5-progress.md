## 本次新增

本轮从远程 `main@28253ce` 继续，完成了 P5-03 的事件桥接加固，并开始实现 P5-04 的
Action Broker 核心。当前仍是 `in_progress`，没有宣称 P5 完成。

1. `src/devpilot/event_bridge.py`
   - 将持久 Run 状态或有限 SSE 事件投影为 nanobot 对话可读的结构化消息；
   - 支持固定事件白名单、字段白名单和文件数量上限；
   - 不向模型暴露绝对路径、原始 stdout/stderr、凭据或 capability token；
   - 输出 `run_id`、状态、阶段消息、错误码、后端、退出码、耗时、Artifact 引用等必要信息。
2. `src/devpilot/nanobot_tools.py`
   - 增加 SSE 读取器，固定使用本地控制面地址；
   - 增加只读 `devpilot_watch_run` Tool；
   - 支持 `last_event_id` 重放；
   - SSE 传输失败时回退到持久 Run 快照，绝不把“没有收到事件”解释为成功。
3. `pyproject.toml`
   - 注册 `devpilot_watch_run` nanobot Tool entry point。
4. `tests/test_p5_event_bridge.py`
   - 覆盖字段/事件脱敏、SSE 顺序与游标、SSE 断线快照回退。
5. `src/devpilot/action_broker.py`
   - 增加受信进程内 Broker、HMAC-SHA256 确认上下文、5 分钟有效期、ChangeSet/hash/项目绑定、
     一次性 confirmation/nonce/消息序列和模型不可见的幂等键；capability token 只在受信回调窗口内存在。
6. `src/devpilot/nanobot_tools.py`
   - 增加 `devpilot_confirmed_action` Tool；Tool schema 不接受 token、确认上下文或幂等键；
     没有 Gateway 注入的受信上下文时返回 `APPROVAL_BROKER_UNAVAILABLE`。
7. `tests/test_p5_action_broker.py`
   - 覆盖合法签名、篡改、过期、重放、快照不匹配和 token 不出结果边界。
