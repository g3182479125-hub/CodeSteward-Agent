## H2 已实现什么

- 在 nanobot 原生 Agent Loop 中叠加动态 ToolRegistry，不创建第二个 Runtime，也不替换
  原有启动时 ToolLoader。
- 受信 developer-owned、`in_process`、`read_only`、非 exclusive、可并发工具支持
  session/project 作用域的 `list`、`load`、`stop`、`status`。
- `load` 使用已登记的精确 `plugin_id@version`，重新校验入口文件 SHA-256，分配
  generation，并让同一进程、同一会话的下一步模型请求看到新工具。
- `stop` 先撤销新调用，再让已取得 lease 的旧调用完成；操作以 `operation_id` 返回，
  不阻塞全局消息消费协程。
- 动态工具受显式 Profile 能力开关、作用域授权和原生命令的用户回合限制；历史聊天文本、
  委派入口和基础 Registry 不能自行恢复已停用工具。
- 原生聊天命令：
  - `/plugins list`
  - `/plugins load <plugin-id>@<version>`
  - `/plugins stop <plugin-id>`
  - `/plugins status <operation-id>`
